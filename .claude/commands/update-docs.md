# 문서 동기화

코드베이스의 실제 상태를 기반으로 문서를 업데이트합니다.

## 작업 항목

### 1. CLAUDE.md 업데이트
- `bin/rails routes`에서 라우트 목록 확인
- `db/schema.rb`에서 모델/테이블 구조 확인
- 새 모델, 서비스, 컨트롤러가 문서에 반영되었는지 확인
- 테스트 명령어, 빌드 명령어가 최신인지 확인

### 2. README.md 업데이트 (존재하는 경우)
- 설치 절차가 최신인지 확인
- 환경변수 목록 (`.env.example` 또는 `config/credentials` 기반)
- 주요 기능 목록

### 3. 기여 가이드 (docs/CONTRIB.md)
- 개발 워크플로우
- 테스트 실행 방법
- 코딩 컨벤션 요약

### 4. 운영 가이드 (docs/RUNBOOK.md)
- 배포 절차
- 모니터링/알림
- 트러블슈팅
- 롤백 절차

### 5. 오래된 문서 감사
- 90일 이상 미수정 문서 식별
- 코드와 불일치하는 내용 표시

## 원칙
- **코드에서 추출**: 수동 작성이 아닌 실제 코드 기반으로 생성
- **존재하는 파일만 수정**: 불필요한 새 파일 생성 금지
- **변경 사항 요약**: 수정 전후를 간결히 보고

## 출력
변경된 파일 목록과 수정 요약을 표시합니다.
