| # | 규칙 | 이유 |

| 1 | 터치 타겟 최소 44x44px | Apple HIG + WCAG 2.5.5 기준 |
| 2 | 모바일 본문 최소 16px | 가독성 + iOS 폼 줌 방지 |
| 3 | 스크롤 방향 일관성 유지 | 가로+세로 혼합은 혼란 유발 |
| 4 | `overscroll-behavior` 설정 | pull-to-refresh 충돌 방지 |

## 안티패턴 탐지 규칙

| 안티패턴 | 탐지 신호 | 대안 |
|---------|----------|------|
| 이모지를 아이콘으로 사용 | ERB에 이모지 직접 삽입 (장식/기능 역할) | Heroicons SVG |
| 호버 없는 클릭 요소 | `cursor-pointer` 누락 + hover 상태 없음 | `transition-colors` + `hover:` 추가 |
| 일관성 없는 카드 스타일 | `rounded-lg`와 `rounded-xl` 혼용 | 프로젝트 표준 통일 |
| CLS 유발 이미지 | `aspect-ratio` 없는 `<img>` 태그 | `aspect-video` / `aspect-square` |
| 과도한 애니메이션 | 3개 이상 동시 `animate-*` | 단일 focal point 애니메이션 |
| 접근성 누락 | `aria-label` 없는 아이콘 버튼 | 필수 추가 |
| 하드코딩 색상 | `bg-teal-500` 등 임의 색상값 | 프로젝트 색상 변수 사용 |
| `h-screen` 사용 | 모바일 주소창으로 레이아웃 깨짐 | `dvh` 사용 |
| 작은 터치 타겟 | 버튼/링크가 44px 미만 | `min-h-[44px] min-w-[44px]` |
| 대비 부족 텍스트 | `text-gray-300 on bg-white` | 4.5:1 대비 비율 준수 |
