# 컨텍스트 관리 — 세션 품질 유지

## 컨텍스트 열화 신호

다음 증상이 나타나면 즉시 대응:
- 같은 세션에서 이전 지시를 잊어버림
- 이미 답한 질문을 반복함
- 프로젝트 규칙에 어긋나는 코드 생성
- 파일 경로나 메서드명을 잘못 기억

## 세션 경계 판단

| 상황 | 조치 |
|------|------|
| 새 기능 (다른 도메인) | 새 세션 시작 |
| 같은 기능, 다음 Phase | Phase 경계에서 `/compact` |
| 디버깅 3회+ 실패 | 새 세션 + findings.md 요약 인계 |
| 대규모 탐색 완료 → 구현 시작 | `/compact` 후 구현 |
| 자동 압축 발생 | 일시 중단, 핵심 상태 보존 확인 |

## 세션 전환 시 인계 절차

진행 중 작업을 새 세션으로 넘길 때:
1. 현재 상태를 `docs/plans/` 또는 `task_plan.md`에 기록
2. 작업 중인 파일 목록 명시
3. 구체적인 다음 단계 기록
